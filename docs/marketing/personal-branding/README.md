Récupérées le 18 nov. 2026 dans la boîte info@ (courriels de Caleb Ralston du 16 nov. : « i made these for you :) »,
« Here's your free workbook »). Les PDF sont dans `caleb-ralston/` sur l'ordinateur de JP, **pas sur GitHub** (73 Mo,
